## 2. Прайс (OpenRouter)

Источник цены переведён с каталога на список эндпоинтов слага; политика выбора
вынесена в конфиг и показана в UI. Остальное — тариф и матчинг — не тронуто.

- [ ] **Починить `rstrip(":free")`** — `app/matcher.py:118` и `app/matcher.py:236`.
      `str.rstrip` режет **набор символов** `{: f r e}`, а не суффикс: `...-large` → `...-larg`,
      `...-reranker` → `...-rank`. Заменить на `removesuffix(":free")`.
- [ ] **Починить дедупликацию индекса.** `app/matcher.py:129`: `if n and or_id not in by_norm`
      — проверяется `or_id` в словаре, ключуемом по `n`; условие практически всегда истинно,
      и модель с тем же нормализованным именем затирает предыдущую. Должно быть
      `n not in by_norm` + осознанный выбор победителя (самая дешёвая / самая свежая).
      **Подорожало после оживления Layer 3** (§1): 5 моделей (`gemma-4-31b`,
      `gemma-4-26b-a4b`, `qwen3-235b-a22b-no-thinking`, `deepseek-v4-flash-high-preview`,
      `nvidia-nemotron-3-super-120b-a12b`) находят `or_id` третьим слоем, но этого id
      нет в обратном индексе `by_norm` → цена не резолвится и модель уходит в unmatched.
- [ ] **Не выбрасывать бесплатные модели.** Отсекающие условия `prompt > 0` убраны
      (оба были мёртвым кодом: `fetch_prices` никто не звал, а `prices` в воркере
      никто не читал), `:free` доезжает до таблицы. **Осталось главное:**
      `scoring.value_score` возвращает `None` при `price <= 0`, поэтому бесплатные
      модели стоят в таблице без value. Это правится в §3 вместе с clamp'ом.
- [ ] **Брать полный тариф.** Сейчас читаются только `prompt` / `completion`.
      Игнорируются `internal_reasoning` (критично для thinking-моделей), `input_cache_read`,
      `input_cache_write`, `request`, `image`. Решить, что входит в цену, и задокументировать.
      Данные для этого уже под рукой: те же поля лежат в `pricing` каждого эндпоинта
      (`app/sources/openrouter.py:_endpoint`), достаточно расширить `Endpoint`.
- [x] **Разобраться с несколькими провайдерами на модель.** Цена берётся из
      `GET /models/{slug}/endpoints`, а не из каталога: каталожный тариф — это тариф
      дефолтного эндпоинта. Замер на живом API (2026-09-07, выборка 41 модели):
      у 51% моделей провайдер не один, у 7 из 21 мультипровайдерных каталог завышал
      цену на 10-180%. На проде из 175 слагов категории `overall` цена изменилась
      у 32 — до −60% (`llama-3.1-8b-instruct` $0.05 → $0.02).
      Политика в `config.yaml` (`sources.openrouter.price`): `min` (по умолчанию) /
      `median` / `catalog`. Критерий сопоставимости — **те же веса, что мерила арена**:
      тиры обслуживания в выборе участвуют (`openai/flex` за $1 — та же модель, что
      `openai` за $2, только в отложенной очереди, и эту цену реально можно заплатить),
      а урезанные веса `fp4`/`int4` исключены — это уже другая модель.
      На `overall` цена ниже каталожной у 52 моделей из 175: флагманы вдвое
      (`gpt-5.5` $5.00 → $2.50 на flex), открытые до −60%
      (`llama-3.1-8b-instruct` $0.05 → $0.02 на fp8 DeepInfra), при этом fp4-дно
      отвергается (`qwen3.8-27b` берёт $0.24 fp8, а не $0.15 fp4).
      В строку снапшота пишется `price_source` (провайдер, тег, квантизация,
      сколько эндпоинтов сопоставимо из скольких, разброс blended min-max);
      в UI это колонка Provider с подсказкой, значок `≈` помечает цену вне
      сопоставимого набора.
- [ ] **Ограничить fuzzy-матч.** Layer 4 (`app/matcher.py:213-220`) матчит между организациями
      при ratio > 0.85 — риск привязать цену чужой модели без единого сигнала. Сохранять в
      снапшот `match_layer` и `match_confidence`, показывать значком в таблице;
      Layer 4 либо выключить, либо явно помечать как ненадёжный.
- [ ] **`created` ≠ дата релиза модели.** Это дата добавления в OpenRouter
      (`app/matcher.py:135`), а используется как «свежесть» при расчёте медианы
      (`app/worker.py:110-118`). Найти корректный источник даты или переименовать метрику.
- [ ] **Санити-чек цен.** Отбрасывать или логировать заведомо аномальное ($0.0001 у флагмана,
      $500/1M) — сейчас любая мусорная цена молча улетает в формулу. Половина данных
      для этого появилась: `price_source.min_blended_1M` / `max_blended_1M` дают разброс
      по слагу, и аномалия видна как выброс относительно собственного слага. Фильтра
      или лога всё ещё нет.

## 3. Формула Value Score

Код и спека расходятся; метрика не ограничена сверху и не интерпретируема.

- [ ] **Синхронизировать SPEC / README / код.** `README.md` описывает метрику как
      «win probability (Elo) × blended price», но `winProb` в `app/scoring.py`
      **отсутствует вообще** — там экспоненциальная эффективная цена. Один из документов врёт.
- [ ] **Определиться, что такое медиана.** `SPEC.md` §2 обещает `median(топ-N по рейтингу)`,
      а `app/worker.py:110-118` считает медиану **самых новых по дате** моделей (все за 60 дней,
      либо `top_n` свежих). Это разные вещи; выбрать одну и переписать вторую.
      Заодно: `TWO_MONTHS = 60 * 24 * 3600` — это 60 дней, не два месяца.
- [ ] **Ограничить взрыв на дешёвых моделях.** `value = 100 / price_eff ** gamma`
      (`app/scoring.py:39`): при `price → 0` значение уходит в бесконечность, при `gamma = 1.0`
      разброс на 3-4 порядка → таблица и цвета точек вырождаются. Ввести clamp, лог-шкалу
      или нормализацию 0..100 внутри категории.
- [ ] **Сделать значение интерпретируемым.** «447.2» ни о чём не говорит. Варианты:
      percentile-ранг внутри категории, «$ за очко Elo сверх baseline», либо явная
      нормализация «лучшая модель = 100».
- [ ] **Пересмотреть `token_share: 0.75`** (`config.yaml:20`). У reasoning-моделей соотношение
      вход:выход другое; сделать параметром UI (слайдер) или пресета, а не глобальной константой.
- [ ] **Проверить пресеты на реальных данных.** `k` и `gamma` (`config.yaml:22-24`) подобраны
      на глаз. Прогнать на снапшоте и посмотреть, различаются ли топ-10 у `quality` /
      `balanced` / `budget` — если нет, пресеты бессмысленны.
- [ ] **Написать тесты на `scoring.py`.** Минимум: монотонность по рейтингу и по цене,
      поведение при `price = 0`, ветка `OverflowError` (`app/scoring.py:41-46` возвращает
      магическое `1e9`).

## 4. График (scatter)

Весь код — `static/index.html:759-915`.

- [ ] **Логарифмическая ось X.** Цены расходятся на 3 порядка ($0.05 … $75), ось линейная
      (`static/index.html:786`) → большая часть точек слипается у левого края.
- [ ] **Защита от деления на ноль.** При `maxP === minP` или `maxR === minR` (одна модель или
      равные цены) координаты становятся `NaN` и точки исчезают без ошибки.
- [ ] **Заменить «эффективную границу» на честный Парето-фронт.** Сейчас это максимум рейтинга
      в каждом из 10 равных бинов (`static/index.html:817-840`): при пустых бинах линия рвётся,
      при выбросах скачет, и это не выпуклая огибающая.
- [ ] **Убрать вторую производную.** Зелёный пунктир (`static/index.html:869-900`) — численная
      d²r/dp² по 10 точкам, отмасштабированная в 40% высоты чужой оси. Шум без легенды:
      либо выкинуть, либо вынести на отдельную ось с подписью.
- [ ] **Разнести подписи.** `idx % 2` (`static/index.html:794`) — не разрешение коллизий;
      при 40+ моделях подписи наезжают. Нужен greedy-алгоритм или подписи только для топ-N.
- [ ] **Ререндер при resize.** `cw` читается один раз (`static/index.html:761`), `ch = 600`
      захардкожен — при изменении ширины окна график остаётся в старой геометрии.
- [ ] **Одна технология рендера.** Сетка и точки — абсолютные `div`, фронт — `svg` поверх.
      Перевести всё в SVG (или Canvas): проще клиппинг, зум, экспорт.
- [ ] **Легенда для цвета.** Точки красятся по value через hue 270→140
      (`static/index.html:790-792`), нигде не объяснено. Плюс hue-градиент плохо читается
      при дальтонизме — взять монотонную палитру (viridis-like).
- [ ] **Мобильная версия.** На <640px подписи просто скрыты (`static/index.html:480`),
      тултип обрезается — график превращается в облако безымянных точек.
      Нужен tap-to-inspect вместо hover.
- [ ] **Клиппинг выбросов.** Точки вне домена рисуются за пределами области построения,
      поверх подписей осей.
